## 🛠️ 如何在客户端中使用分流？

1. **Clash Verge Rev**: 在 `Proxies (代理)` 页面顶部，将模式切换为 **Rule (规则模式)**。
2. **Shadowrocket**: 打开首页，将顶部模式设置为 **Config (配置/规则)**。
3. **v2rayNG**: 进入设置，将路由模式设置为 **绕过局域网及大陆 (Bypass LAN & Mainland)**。
